# "This item is currently unsupported"

This error usually occurs when you try to download an unsupported item from the Store.

### Possible fixes

- Update the application to the latest version.
- Change the Store version control on the [Settings] page of the Store. Then the application downloads the database from a different source. This source can have a supported version of the item.

### If the problem continues

- The application possibly does not support this item at this time. A future version can support it.
- An error possibly occurred. Send a report to the technical support of the application. Attach the necessary logs and give a detailed description of the problem. This is important. The [About] page of the main window shows the technical support address.
