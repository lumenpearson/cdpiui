# Add custom sites to the bypass list

To change the list of sites and IP addresses for the bypass, open the preset settings of the component that you use.

If the preset uses site lists, the [Site lists] widget shows. This widget shows all sites for the bypass.

To edit a site list:

1. Find the site list in the [Site lists] widget.
2. Click [Edit] next to the name of the list.
3. Edit the list in the default editor for .txt files.

To see the arguments for a site list:

1. Click [View more actions] next to the list.
2. Select [View applied params].

### Note

Site lists and IP lists are not unique to each preset. When you change a list, the change applies to all presets in the set. The exception is the "Local user data" set (StoreId: `LocalUserStorage`).

### For advanced users

The Store shows the working directories of preset sets.

1. Open the [Library] page in the Store.
2. Click [View more actions] for the item.
3. Select [Show local files] in the menu.
