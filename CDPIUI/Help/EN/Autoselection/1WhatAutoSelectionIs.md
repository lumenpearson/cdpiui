# What is auto-selection?

Auto-selection helps you find a method to get access to the sites that you need. The application does the checks and compares the options. Usually, you do not need to try technical parameters manually.

### Which tools are available?

- **Preset selection for Zapret2.** This tool tests different Zapret2 strategies on the selected sites. It uses the successful results to make a personal preset.
- **Select the best preset.** This tool compares the installed presets and the presets that you made. It helps you select the best preset.
- **Create a new preset with GoodCheck.** This tool helps you make a new preset for [Zapret Legacy], [ByeDPI] and [GoodbyeDPI] when the ready-made presets do not operate.

### Which tool must I use?

If you use **Zapret2**, start with the [preset selection for Zapret2](cdpiui://Help/Zapret2PresetSelection/1AboutPresetSelection/). It is the simplest tool. Select the sites and a scan mode. During the scan, the internet connection on this device can be unavailable.

Use [Select the best preset](cdpiui://Help/Autoselection/BestConfigSelection/) if you have some presets. This tool finds the preset that operates best with the necessary sites.

**For advanced users.** Use GoodCheck when the ready-made presets for [Zapret Legacy], [ByeDPI] or [GoodbyeDPI] do not help. You must test and adjust the result yourself. To open this tool, use [Auto-selection tools] on the [Utilities] page.

### How do I start a Zapret2 scan?

- [Start a new scan](cdpiui://Tools/AutoConfig/Zapret2/)
- [Show previous scans](cdpiui://Tools/AutoConfig/Zapret2/Reports)
- [Read the step-by-step guide](cdpiui://Help/Zapret2PresetSelection/1AboutPresetSelection/)

If the automatic result does not operate, read [Build a preset manually](cdpiui://Help/Zapret2ManualPresetBuilding/1ManualPresetOverview/). This guide tells you how to select successful strategies from the report, put them in the correct sequence and test the preset.
