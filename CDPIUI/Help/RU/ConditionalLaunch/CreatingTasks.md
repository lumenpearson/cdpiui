# Создание и изменение задачи

Откройте [Условный запуск] на странице [Утилиты].

### Создание задачи

1. Нажмите [Создать задачу] на панели инструментов.
2. На странице [Общие] укажите имя.
3. Выберите приоритет.
4. Оставьте флажок [Выполнять задачу при срабатывании триггера], если задача должна быть активна.
5. Выберите, нужно ли останавливать задачу после ошибки.
6. На странице [Триггеры] добавьте условие запуска.
7. На странице [Действия] добавьте нужные действия.
8. Расположите действия в правильном порядке.
9. Нажмите [ОК].

Приложение автоматически предлагает уникальное имя. При необходимости его можно изменить.

### Изменение и проверка

Дважды щёлкните по задаче, чтобы изменить её.

Чтобы проверить задачу без триггера:

1. Выберите задачу.
2. Нажмите [Выполнить].

### Импорт и экспорт

Выберите [Импортировать задачу из файла] или [Экспортировать выбранную задачу] на панели инструментов. Одна задача хранится в одном файле `.cdpitask`.

Далее: [Триггеры и действия](cdpiui://Help/ConditionalLaunch/TriggersAndActions/).
