# Первые шаги

Это руководство показывает основы работы с CDPI UI и начальную настройку.

### Скачайте первый компонент

1. Откройте Магазин.
2. Скачайте нужный компонент.

На данный момент готовые пресеты есть только для Zapret. Для ByeDPI нужен пресет, подобранный через GoodCheck. GoodCheck находится в разделе «Надстройки» Магазина.

### Подготовьте компонент

1. Откройте страницу настроек установленного компонента.
2. Выберите пресет, который хотите использовать.

Если компонент запущен, он автоматически перезапустится после смены пресета. Некоторые приложения и службы нужно перезапустить, чтобы они правильно показали доступность.

### Настройте автозапуск компонента

1. Откройте страницу [Параметры] в главном окне.
2. Выберите [Автозапуск].
3. Включите переключатель [Открывать приложение при запуске ПК].
4. Откройте настройки установленного компонента.
5. Установите флажок [Запускать автоматически].

Настройка приложения завершена.

### Если некоторые сервисы стали недоступны

- **Проверьте наличие обновлений.** Откройте страницу [Загрузки] в Магазине. Обновите элементы, для которых есть обновления.
- **Выберите другой пресет.** Снова попробуйте пресеты из списка. Один из них может заработать.
- **Воспользуйтесь подбором через GoodCheck.** Откройте страницу [Утилиты]. Выберите [Средства автоподбора]. Должно быть установлено дополнение «GoodCheck».
