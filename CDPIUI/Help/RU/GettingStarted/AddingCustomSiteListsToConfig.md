# Добавление своих URL-адресов для обхода

Чтобы изменить список сайтов и IP-адресов, для которых выполняется обход, откройте настройки пресета используемого компонента.

Если пресет использует списки сайтов, показывается виджет [Списки для обхода]. В этом виджете перечислены все сайты, для которых выполняется обход.

Чтобы изменить список сайтов:

1. Найдите список в виджете [Списки для обхода].
2. Нажмите [Изменить] рядом с названием списка.
3. Измените список в редакторе .txt-файлов по умолчанию.

Чтобы просмотреть аргументы, которые применяются к списку сайтов:

1. Нажмите [Показать больше действий] рядом со списком.
2. Выберите [Показать применяемые флаги запуска].

### Примечание

Списки сайтов и IP-адресов не уникальны для каждого пресета. Если изменить список, изменение применится ко всем пресетам набора. Исключение — набор «Личные данные текущего пользователя» (StoreId: `LocalUserStorage`).

### Для продвинутых пользователей

Рабочие директории наборов пресетов можно узнать через Магазин.

1. Откройте страницу [Библиотека] в Магазине.
2. Нажмите [Показать больше действий] у нужного элемента.
3. Выберите [Показать локальные файлы] в меню.
