# Утилита поиска и устранения неполадок

Утилита [Поиск и устранение неполадок] находит частые проблемы на вашем ПК и пытается их исправить.

Открыть утилиту можно на странице [Утилиты] главного окна приложения.

### Выбор проблемы

На первой странице показан список проблем. Выберите свою проблему:

| Проблема | Что делает утилита |
| -------- | ------------------ |
| [Ни один пресет не позволяет получить доступ к необходимым сайтам] | Запускает базовую проверку системы. |
| [Компонент постоянно вылетает с ошибкой] | Открывает статью справки об ошибках компонентов. |
| [Я не могу открыть Магазин или скачать элемент из него] | Запускает проверку Магазина. |
| [Моей проблемы нет в списке] | Открывает страницу для отправки сообщения о проблеме. |

### Базовая проверка системы

Перед проверкой утилита останавливает все компоненты. Проверяются:

- служба Base Filtering Engine;
- системный прокси-сервер;
- наличие `netsh.exe` в переменной PATH;
- параметр TCP timestamps;
- службы AdGuard, Killer, Intel Connectivity Network, Check Point и SmartByte;
- службы VPN-провайдеров;
- системный DNS-сервер;
- служба WinDivert, другие запущенные компоненты обхода и их службы.

### Проверка Магазина

Перед проверкой утилита останавливает все компоненты. Проверяются:

- доступ к репозиториям Магазина на GitHub и GitLab;
- права записи в директории Магазина: внутреннюю директорию, директорию элементов, локальную директорию репозитория и директорию базы данных.

### Результаты и исправление

1. Дождитесь завершения проверки. Окно командной строки может мерцать во время проверки.
2. Изучите таблицу результатов.
3. Нажмите [Далее], чтобы исправить найденные проблемы.
4. Дождитесь завершения исправления.
5. Изучите результаты исправления.
6. Нажмите [Выход].

Утилита исправляет не все проблемы автоматически. Она может включить TCP timestamps, остановить службу WinDivert и выдать права записи в директории Магазина. Для остальных проблем используйте ссылку на справку рядом с результатом.
