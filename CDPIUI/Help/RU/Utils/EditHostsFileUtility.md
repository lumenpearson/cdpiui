# Изменение файла HOSTS на вашем ПК

Начиная с версии 0.5.0.0 в приложение встроена утилита, позволяющая изменить файл HOSTS на вашем ПК. 

В процессе использования утилиты может мерцать окно консоли.

### Зачем это нужно?

Изменение файла HOSTS позволяет решить следующие проблемы:

1. Исправить подключение к серверам Discord, расположенным в Финляндии.
2. Вернуть доступ к серверам GitHub, которые необходимы для получения обновлений приложения и корректной работы Магазина.

Подробную информацию о работе файла HOSTS и его восстановлении в Windows можно найти по адресу: [сайт поддержки Майкрософт](https://support.microsoft.com/ru-ru/topic/c2a43f9d-e176-c6f3-e4ef-3500277a6dae).

### Как добавить адреса в файл?

*Примечание:* Если пункт [Добавить адреса в файл hosts] недоступен, адреса уже добавлены в файл.

1. Откройте [Утилита изменения файла hosts] на странице [Утилиты] главного окна.
2. Выберите [Добавить адреса в файл hosts].
3. Согласитесь с предоставлением прав администратора процессу `EditHostFile.exe`. Это обязательно, иначе изменить файл не получится.
4. Убедитесь, что в верхней части окна утилиты показан статус «Файл hosts был изменён».

### Как удалить адреса из файла?

*Примечание:* Если пункт [Убрать адреса из файла hosts] недоступен, изменения в файл hosts не вносились.

1. Откройте [Утилита изменения файла hosts] на странице [Утилиты] главного окна.
2. Выберите [Убрать адреса из файла hosts].
3. Согласитесь с предоставлением прав администратора процессу `EditHostFile.exe`. Это обязательно, иначе изменить файл не получится.
4. Убедитесь, что в верхней части окна утилиты показан статус «Файл hosts не изменён».

### Как восстановить файл?

Восстановление удаляет добавленные адреса из файла hosts и удаляет резервную копию `hosts.bak`. Изменения, которые другие приложения внесли после создания резервной копии, остаются в файле.

*Примечание:* Если пункт [Восстановить оригинальный файл hosts из резервной копии] недоступен, резервной копии нет. Утилита создаёт резервную копию при добавлении адресов.

1. Откройте [Утилита изменения файла hosts] на странице [Утилиты] главного окна.
2. Выберите [Восстановить оригинальный файл hosts из резервной копии].
3. Согласитесь с предоставлением прав администратора процессу `EditHostFile.exe`. Это обязательно, иначе восстановить файл не получится.
4. Убедитесь, что в верхней части окна утилиты показан статус «Файл hosts не изменён».
5. Убедитесь, что кнопка восстановления недоступна.


## Возможные ошибки 

Антивирусы могут пометить файл `EditHostFile.exe` как вредоносный и удалить его. В случае удаления файла приложение будет выдавать ошибку вида `APPLICATION_DAMAGED_NEED_REPAIR` при попытке изменить файл hosts. 

Чтобы решить эту проблему:

- Для Portable-версии скопируйте файл `EditHostFile.exe` из актуального Portable-релиза в директорию приложения рядом с `CDPIUI.exe`.
- Для MSI-версии выполните восстановление установки.

Для ручной отладки можно запустить `EditHostFile.exe` через терминал с правами администратора и отследить консольный вывод. 

| Флаг запуска утилиты | Описание |
| -------------------- | -------- |
| /add | Добавить адреса в файл hosts |
| /remove | Удалить адреса из файла hosts |
| /recover | Удалить добавленные адреса из файла hosts и удалить файл hosts.bak |

## Для разработчиков

В утилиту встроен файл hosts из репозитория [zapret-discord-youtube](https://raw.githubusercontent.com/Flowseal/zapret-discord-youtube/refs/heads/main/.service/hosts). Любые его изменения влекут за собой пересборку утилиты (из соображений безопасности).

Добавляемые адреса помечаются тегом `[CDOM-B]` в начале и `[CDOM-E]` в конце добавляемого списка для упрощения их последующего удаления и редактирования.
