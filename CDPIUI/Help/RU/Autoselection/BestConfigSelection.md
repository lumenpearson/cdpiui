# Подбор лучшего пресета

Это средство подбирает лучший пресет для компонента из уже загруженных или созданных пресетов.

Чтобы открыть это средство:

1. Откройте страницу [Утилиты] главного окна.
2. Откройте утилиту [Средства автоподбора].
3. Выберите компонент.
4. Выберите [Подобрать лучший пресет автоматически].

### Окно утилиты

Окно имеет три области:

- **Настройки.** Здесь до запуска теста задаются настройки подбора.
- **Результаты.** Здесь после теста показываются результаты подбора.
- **Вывод.** Здесь показывается ход текущего подбора.

### Настройка тестирования

Прежде чем начать подбор, убедитесь, что следующие параметры указаны правильно:

- **Компонент.** Убедитесь, что выбран нужный компонент.
- **Тип теста.** Выберите тип тестирования. [Стандартные тесты (HTTP/пинг)] выполняются быстрее, но не выявляют некоторые виды блокировок. [Проверка DPI (заморозка TCP 16-20)] работает дольше: каждый запрос замораживается, чтобы точно выявить блокировку.
- **Какие пресеты тестировать.** Выберите пресеты для теста. Если вы не уверены, оставьте [Все пресеты].

Для стандартных тестов также настройте список сайтов. Чтобы открыть его, нажмите [Список сайтов для теста] в нижней части области настроек. Проверка DPI не использует этот список: она загружает свой список сайтов из интернета.

Список имеет следующий формат:

```
НАЗВАНИЕ_САЙТА = URL-адрес_сайта
```

URL-адрес может иметь один из двух видов:

- **Стандартный.** URL начинается с `http://` или `https://`. Выполняются пинг и проверка подключения HTTP или HTTPS.
- **Только пинг.** URL начинается с `PING:`. Выполняется только пинг.

Название — это отображаемое имя сайта в файле журнала и во время подбора. Оно не влияет на подбор и может быть любым. Используйте в названии только английские буквы.

### Запуск тестирования

1. Нажмите [Запустить тест].
2. Дождитесь завершения теста.

Подбор может занять от нескольких минут до часа. Время зависит от провайдера и количества тестируемых пресетов.

Во время подбора можно пользоваться компьютером. Приложения, использующие сеть, могут выдавать ошибки.

Чтобы завершить подбор досрочно, нажмите [Остановить тест]. В области результатов будут показаны сведения о пресетах, которые тест уже проверил.

### Просмотр результатов

Когда подбор завершён, изучите результаты. Убедитесь, что предложенный пресет вам подходит, и примените его.

### Что делать, если ни один пресет не подошёл?

- Откройте утилиту [Поиск и устранение неполадок] на странице [Утилиты] главного окна. Выберите [Ни один пресет не позволяет получить доступ к необходимым сайтам]. Дождитесь окончания проверки. Выполните рекомендуемые действия и повторите тестирование.
- Загрузите новые наборы пресетов из Магазина.
- Обратитесь в техническую поддержку.
