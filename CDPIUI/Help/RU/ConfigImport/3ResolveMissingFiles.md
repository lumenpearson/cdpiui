# Отсутствующие файлы

Некоторые пресеты используют отдельные списки сайтов, BIN-файлы или LUA-библиотеки. Если мастер не нашёл такой ресурс по ожидаемому пути, он попросит выбрать решение. Без решения для каждого отсутствующего файла продолжить сохранение нельзя.

### Доступные действия

- **Применить автокоррекцию** — использовать файл, который CDPI UI нашёл в другой подходящей папке. Перед применением проверьте предложенный путь.
- **Выбрать файл** — указать существующий файл самостоятельно. Лучше использовать ресурс из того же набора пресета и с ожидаемым расширением.
- **Создать пустой** — сохранить пустой файл вместо отсутствующего.

Пустой файл подходит только тогда, когда ресурс действительно необязателен. Например, некоторые пользовательские списки или файлы журнала могут начинаться пустыми.

ВНИМАНИЕ: Не заменяйте обязательную LUA-библиотеку или BIN-файл пустым файлом. Делайте это, только если автор пресета сообщает, что файл необязателен.

Для файлов, в названии которых есть `user` или `debug`, мастер может сразу предложить создание пустого файла. Это подсказка, а не гарантия совместимости.

Если для всех оставшихся файлов есть предложения автокорректора, нажатие **Продолжить** применит их автоматически. Если хотя бы для одного файла предложения нет, сначала выберите действие вручную.

При сохранении нужные ресурсы копируются в отдельное хранилище CDPI UI. Исходные файлы остаются на прежнем месте и не удаляются.
