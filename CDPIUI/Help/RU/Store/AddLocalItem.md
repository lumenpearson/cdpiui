# Добавление элемента из локального пакета

Начиная с версии 0.3.0.0 Магазин поддерживает установку и обновление элементов из локальных пакетов.

### Для чего это нужно?

Функция локальной установки элементов и обновлений может быть полезна, если:

- По какой-либо причине приложение не может получить доступ к серверу Магазина для скачивания и обновления элементов.
- Вы хотите установить старую версию элемента, которая недоступна через Магазин.
- Элемент, который вы хотите установить, в настоящий момент не представлен в Магазине.
- Требуется выполнить локальное развертывание приложения как можно быстрее, игнорируя Магазин.

### Это безопасно?

Несмотря на то, что все пакеты проходят обязательную сертификацию и приложение проверяет целостность подписи пакета, не стоит терять бдительность.
Даже подписанный пакет может содержать в себе вредоносное ПО.

ПРЕДУПРЕЖДЕНИЕ: Устанавливайте пакет только в том случае, если вы полностью уверены в его безопасности и доверяете поставщику.

### Какие бывают виды пакетов?

| Тип пакета | Подпись | Содержимое |
| ---------- | ------- | ---------- |
| **CDPISIGNEDPACK** | Есть | Стандартный пакет. Может содержать дополнение, компонент или набор пресетов. |
| **CDPICONFIGPACK** | Нет | Пакет для наборов пресетов. Может содержать только набор пресетов. Типы файлов, которые можно распаковать, ограничены. |
| **CDPIPATCH** | Есть | Пакет обновления приложения. Содержит файлы для обновления приложения. |

### Как установить локальный пакет?

Используйте один из следующих способов.

**Способ 1**

1. Перетащите пакет на ярлык приложения.

**Способ 2**

1. Щёлкните файл пакета правой кнопкой мыши.
2. Выберите [Открыть с помощью].
3. Укажите исполняемый файл приложения `CDPIUI.exe`.

**Способ 3**

1. Откройте Магазин.
2. Откройте страницу [Параметры].
3. Выберите [Добавить элемент из локального пакета].
4. Прочитайте предупреждение. Чтобы принять риски, нажмите [Все равно продолжить].
5. Выберите файл пакета.

Откроется диалог с предложением установить элемент. Для пакета CDPIPATCH откроется диалог обновления приложения.

1. Выберите [Установить].
2. Дождитесь завершения установки.
