# EditHostFile

`EditHostFile.exe` — консольная утилита на .NET Framework 4.7.2. Она добавляет блок CDPI UI в файл hosts Windows
(`%WINDIR%\system32\drivers\etc\hosts`) или удаляет его оттуда. Её манифест требует
права администратора (`EditHostFile/app.manifest`). Вся логика находится в `EditHostFile/Program.cs`.

## Аргументы

| Аргумент   | Действие |
|------------|--------|
| `/add`     | Удаляет существующий блок. Записывает `hosts.bak`. Добавляет блок из `Data/hosts` в конец файла. |
| `/remove`  | Удаляет блок. Если блока нет, утилита не записывает файл. |
| `/recover` | Удаляет блок. Затем удаляет `hosts.bak`. Утилита не копирует резервную копию обратно. |

Утилита использует только первый найденный аргумент в таком порядке: `/remove`, `/add`, `/recover`.

## Файл hosts отсутствует

Если файла hosts нет, утилита читает его как пустой файл:

- `/add` записывает пустой `hosts.bak`. Затем создаёт файл hosts с блоком. Новый файл использует UTF-8 без BOM и переносы строк `\r\n`.
- `/remove` не находит блок. Утилита не создаёт файл.
- `/recover` не находит блок. Утилита удаляет `hosts.bak`, если он существует.

## Управляемый блок

Блок — это встроенный ресурс `EditHostFile/Data/hosts`. Его первая строка начинается с
`# [CDOM-B]`. Его последняя строка начинается с `# [CDOM-E]`.

Чтобы удалить блок, утилита удаляет весь текст от `# [CDOM-B]` до конца строки `# [CDOM-E]`.
Утилита также удаляет перенос строки после неё.

ВНИМАНИЕ: Не добавляйте в блок записи вручную. Следующий вызов `/add` или `/remove` удалит их.

Правила для `/add`:

- Утилита не добавляет строку ресурса, если такая же строка уже есть в файле вне блока. Это правило действует только для строк, которые не являются комментариями и не пусты.
- Утилита всегда добавляет строки комментариев и пустые строки.
- Если файл не заканчивается переносом строки, утилита добавляет его перед блоком.

## Кодировка и переносы строк

Утилита читает файл как байты и сохраняет его кодировку:

| Начало файла | Кодировка, которую использует утилита |
|------------|-----------------------------|
| Метка порядка байтов (BOM) UTF-8 | UTF-8 с BOM |
| BOM UTF-16 LE | UTF-16 LE с BOM |
| BOM UTF-16 BE | UTF-16 BE с BOM |
| Нет BOM, корректный UTF-8 | UTF-8 без BOM |
| Нет BOM, некорректный UTF-8 | Кодовая страница ANSI |

Утилита определяет тип переноса строк так:

- Если файл содержит `\r\n`, утилита использует `\r\n`.
- Если файл содержит только `\n`, утилита использует `\n`.
- Если в файле нет переносов строк, утилита использует `\r\n`.

Новые строки получают тип переноса строк файла. Утилита не изменяет существующий текст.

## Резервная копия и замена

Перед изменением `/add` записывает `hosts.bak` в папку файла hosts. Резервная копия содержит
файл без блока CDPI UI в той же кодировке.

При каждой записи утилита выполняет такие шаги:

1. Записывает новое содержимое в `hosts.cdpiui.tmp`.
2. Сбрасывает файл на диск.
3. Заменяет целевой файл через `File.Replace`. Если целевого файла нет, использует `File.Move`.
4. Удаляет временный файл, если он остался.

Поэтому файл hosts никогда не бывает записан наполовину.

## Коды выхода

| Код | Значение |
|------|---------|
| `0` | Успех. Сюда входит и `/remove`, когда блока нет. |
| `0x80070057` (`E_INVALIDARG`) | В командной строке нет известного аргумента. |
| Другой | `HResult` исключения, которое остановило утилиту. Если `HResult` равен `0`, код равен `1`. |

Утилита пишет ход работы и ошибки в стандартный вывод с префиксом `[CDPI UI/EditHostFileHelper]`.

## Вызывающие компоненты

| Вызывающий компонент | Вызов |
|--------|------|
| `HostsFileEditService` (`CDPIUI.AddOns/HostsFileEditor/HostsFileEditorService.cs`) | Запускает утилиту из папки приложения с глаголом `runas`. Возвращает код выхода. Страница редактора hosts (`CDPIUI/Views/EditHostsFile/MainPage.xaml.cs`) преобразует код в ошибку с префиксом `HOSTEDIT`. |
| Очистка при удалении MSI (`CDPIUI_TrayIcon.exe --uninstall-cleanup`, работает от имени SYSTEM) | Запускает `EditHostFile.exe /remove`. Ждёт не более 15 с (`CDPIUI.TrayIcon/Helper/UninstallHelper.cs`). |
