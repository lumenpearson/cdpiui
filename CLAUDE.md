# CDPI UI fork instructions

Read and follow [AGENTS.md](AGENTS.md) for every task in this fork.
It is the canonical instruction file for Codex, Claude and other coding agents.

Create or reuse a detailed issue before implementation. Set and read back its canonical labels, owner, milestone and Project 7 fields.
Maintain progress, decisions, documentation and revision-specific verification in that issue.
After every scoped acceptance criterion passes, post the acceptance record, close the issue as `completed` and set Project Status `Done` immediately.
Read back both states before reporting completion. A merged PR or a green build alone is insufficient.

Use [the detailed task lifecycle](docs/task-lifecycle.md) for the issue and close-out formats.
Keep local stage completion separate from integration, installed-product acceptance and release gates.
